# yaw 实验版仿真与实机标定清单

本文件只列新增或因旋转而变得更重要的项目。平移 `M_t`、`D_L`、相机噪声、三轴力和电机符号仍按主融合目录的 `CALIBRATION_CHECKLIST.md` 执行。

## A. 上仿真前

- [ ] `python -m unittest discover -s .\MPC_dual_model_yaw\tests -v` 全部通过。
- [ ] 闭环仿真中 `alpha` 收敛，`r`、`N`、`delta_N` 不越限。
- [ ] 目标惯性静止、ROV 只 yaw 的测试中，估计 `v_rel` 接近零。
- [ ] 检查 OSQP 单周期 95% 耗时明显小于 50 ms。
- [ ] 人为让 QP 失败，确认保持上一可行输入或限速回到锁存基线。

## B. 坐标系和时间戳

- [ ] 标定相机到机体系旋转 `R_bc`，不要直接沿用示例矩阵。
- [ ] 测量机体控制原点到相机光心的杠杆臂 `r_bc_body`。
- [ ] 确认机体 FRD：`x` 前、`y` 右、`z` 下。
- [ ] 确认正 yaw/r/N 都表示艏向右转。
- [ ] 相机 3-D 位置、IMU yaw 和 yaw rate 对齐到同一拍摄时间戳。
- [ ] 验证 yaw 从 `+pi` 跨到 `-pi` 时增量仍连续。
- [ ] 测量并补偿 IMU yaw-rate 零偏。

## C. 艏摇动力学辨识

- [ ] 有效艏摇惯量 `m_r=I_z-N_rdot`。
- [ ] 低速线性艏摇阻尼 `d_r`。
- [ ] 若高速段残差明显，记录二次阻尼数据；当前 QP 还未使用 `d_rr|r|r`。
- [ ] 测量 yaw 归一化通道达到 `+0.20` 时的实际艏摇力矩。
- [ ] 反向通道单独测量；若正反推力不对称，不能继续使用单一线性比例。

## D. 约束和权重

- [ ] `yaw_moment_min/max` 使用实际可达而非铭牌极限。
- [ ] `delta_yaw_moment_min/max` 能抑制电机突变且不使响应过慢。
- [ ] `yaw_rate_min/max` 低于视觉模糊、控制失稳或线缆风险阈值。
- [ ] 先调 `line_of_sight_angle_weight`，使目标回到水平中央。
- [ ] 再增大 `yaw_rate_weight` 抑制过快转头。
- [ ] 用 `yaw_moment_weight` 和 `delta_yaw_moment_weight` 抑制持续大力矩及抖动。
- [ ] 检查平移和 yaw 同时请求时的 8 推进器饱和；当前 QP 尚无联合可达域约束。

## E. 上水顺序

- [ ] 拆桨或固定机体，逐一核对 X/Y/Z/roll/pitch/yaw 六轴符号。
- [ ] 只启用 yaw，限幅为预计可用值的 10%--20%，验证目标在右侧时输出正 N。
- [ ] 只做原地低速 yaw，验证纯旋转不会产生明显 `v_rel`。
- [ ] 再启用平移和 yaw 联合控制，记录 QP 状态、求解耗时、slack、alpha、r、N 和八电机饱和。
- [ ] 出现时间戳跳变、IMU 无效、视觉丢失或连续 QP 失败时立即退出自动跟踪。
